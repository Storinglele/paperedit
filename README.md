# PaperEdit

PaperEdit 是一款本地 PDF 文字编辑器，支持 macOS 和 Windows。可以修改 PDF 中的原有文字、添加新文字，并将结果另存为 PDF。

## 功能

- **修改原有文字**：直接点击页面中的中文或英文文字进行编辑。
- **添加文字**：在页面空白处输入新内容。
- **调整文字样式与位置**：修改字号、颜色，移动文字框或调整大小。
- **优先保留原字体**：尽量保持原文外观；需要使用替代字体时会提示。
- **阅读与查找**：页面缩略图、缩放、文字搜索和复制。
- **撤销与重做**：返回之前的编辑状态。
- **另存为 PDF**：保留原文件，导出的文字可以被搜索和提取。
- **导出 Word**：将可提取文字的 PDF 转换为可编辑的 `.docx`，尽量保留图片、表格和分页。

文档在电脑本地处理，无需上传 PDF。发行包已包含运行环境，无需安装 Python。

## 下载

前往 [GitHub Releases](https://github.com/Storinglele/paperedit/releases/latest) 下载适合你的版本。

| 系统 | 下载文件 | 启动方式 |
| --- | --- | --- |
| macOS · Apple Silicon | `PaperEdit2-macOS-arm64.zip` | 解压后打开 `PaperEdit2.app` |
| Windows 10/11 · x64 | `PaperEdit2-Windows-x64.zip` | 解压整个文件夹后打开 `PaperEdit2.exe` |

Windows 版为免安装软件，可将整个文件夹复制到其他位置或 U 盘。请保留 `_internal` 文件夹，不要单独移动 EXE。

Mac 版尚未进行 Apple 公证。当前仓库为私有，下载需要登录有访问权限的 GitHub 账号。下载页提供 `SHA256SUMS.txt`，可用于校验压缩包。

## 使用

### 修改文字

1. 打开 PDF，点击需要修改的文字。
2. 在页面编辑框中输入内容；右侧可调整字号、颜色和文字框。
3. 点击“完成编辑”，或按 **Ctrl+Enter**（Mac：**⌘Enter**）。
4. 点击“另存为”，保存到新 PDF 文件。

保存或切换页面时会自动应用正在输入的内容。无法应用时会保留输入并提示原因。

### 添加文字

选择“添加文字”，点击页面空白位置，输入内容后完成编辑并另存。

### 调整文字框

拖动文字框顶部的柄可移动位置，拖动右下角的柄可调整大小，也可以使用右侧的“自适应文字框”。文字超出可用空间时，根据提示增加文字框大小或减小字号。

### 导出 Word

1. 打开 PDF，并按需要完成文字修改。
2. 选择“导出 Word”，确认保存位置。
3. 在 Word 或 WPS 中继续编辑生成的 `.docx` 文件。

转换在本地完成，不需要安装 Word、WPS 或 Python。第一版支持能选中文字的 PDF；扫描件中的文字需要 OCR，图片页只能作为图片保留。复杂多栏、特殊字体或不规则表格可能需要在 Word 中调整。

## 支持范围

- 支持 PDF 中可提取的水平文字片段，包括中文和英文。
- 支持页面整体旋转后的阅读与编辑。
- 扫描图片可以阅读和添加文字，图片中的原文字无法直接修改；暂不提供 OCR。
- 暂不支持文字自身竖排或倾斜、段落自动重排和图片编辑。
- 含特殊字体效果、特殊页面缩放或与其他内容重叠的文字，可能无法直接替换，软件会提示原因。
- 加密 PDF 需要正确的打开密码，编辑受文档权限限制；另存时保留密码保护与权限设置。
- 输入框使用临时字体预览，点击“完成编辑”后可查看 PDF 的实际显示效果。
