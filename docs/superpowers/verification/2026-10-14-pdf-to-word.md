## 实施决定与代价

1. 复用已隔离的 GitHub staging checkout，避免干扰原项目索引锁；代价是交付前需同步源代码回本地项目。
2. 原子私有 JSON 文件替代标准输入输出通信，支持 Windows 无控制台程序；代价是工作进程协议发生变更。
3. 遗留任务清理从开始导出扩展到应用启动，满足临时数据清理要求；代价是启动时扫描转换缓存。
4. Windows 实际行为通过 Windows CI 的解压启动和转换验证；代价是没有用户机器上的交互测试。
5. Word 排版通过人工样例和办公渲染验证；代价是不能保证复杂 PDF 与原版或 UPDF 完全相同。
6. 现有 PDF 编辑器中与转换无关的缺陷不扩展本次范围；代价是它们仍需单独反馈和处理。

复核没有遗留的次要事项。原 v0.1.0 发行包保留，可用于回退。
